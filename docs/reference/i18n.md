# `gesso.i18n`

Translation catalogs, language detection and lookup. **No third-party
dependencies.**

```python
from gesso.i18n import Translator, DirectorySource, MappingSource
```

## `Translator`

Loads and looks up translations for one language.

```python
class Translator:
    def __init__(
        self,
        sources: Sequence[TranslationSource] = (),
        *,
        language: str | None = None,
        fallback: str = "en",
        include_framework: bool = True,
        framework_dir: Path | None = None,
    ) -> None
```

| Parameter | Meaning |
| --- | --- |
| `sources` | Catalog sources, lowest priority first |
| `language` | Active language. `None` (default) detects it from the environment |
| `fallback` | Language used for missing keys |
| `include_framework` | Prepend Gesso's own `gesso.*` catalogs |
| `framework_dir` | Override where the framework catalogs are read from |

An `include_framework=True` source is always consulted **first**, so it has the
lowest priority.

### `Translator.for_app`

```python
@classmethod
def for_app(
    cls,
    context: AppContext,
    *,
    language: str | None = None,
    locale_dir: Path | None = None,
    source: TranslationSource | None = None,
    fallback: str = "en",
    include_framework: bool = True,
) -> Translator
```

Assembles the standard layering, in ascending priority: `locale_dir`, then
`<config_dir>/i18n` for the user's overrides, then `source`.

### Properties

| Name | Returns |
| --- | --- |
| `language` | The active language code |
| `fallback` | The fallback language code |
| `sources` | The sources, in priority order (last wins) |

### Methods

| Signature | Description |
| --- | --- |
| `t(key_name, /, *, default=None, **kwargs)` | Translate a dotted key, formatting `{placeholders}`. Returns `default`, else the key, when nothing matches. The key is positional-only, so a placeholder may itself be named `key` |
| `has(key_name, /)` | Whether the key resolves to a string |
| `set_language(language)` | Switch language and reload every catalog |
| `languages()` | Every language any source can provide, sorted |
| `catalogs()` | A deep copy of the merged catalog, for inspection |

```python
>>> translator.t("myapp.greeting", name="Ada")
'Hello, Ada!'
>>> translator.has("myapp.greeting")
True
```

## Sources

Both sources implement the same informal contract: `catalog(language) -> dict`
and `languages() -> list[str]`. The translator never learns where catalogs came
from, which is what leaves room for a gettext backend later.

### `DirectorySource`

```python
@dataclass(frozen=True)
class DirectorySource:
    path: Path
    name: str = ""
```

A directory of `<language>.json` files. A missing directory, an unreadable
file, or malformed JSON all degrade to an empty catalog rather than raising —
translations are not worth a traceback at startup.

| Method | Returns |
| --- | --- |
| `catalog(language)` | The catalog dict, or `{}` |
| `languages()` | Language codes found in the directory, sorted |

### `MappingSource`

```python
@dataclass(frozen=True)
class MappingSource:
    catalogs: Mapping[str, Mapping[str, Any]]
    name: str = "<memory>"
```

An in-memory catalog keyed by language. Useful in tests, and for applications
embedding a handful of strings rather than shipping a directory.

## Language functions

### `normalize_lang(code)`

```python
normalize_lang("en_US.UTF-8")   # 'en'
normalize_lang("pt-BR")         # 'pt'
normalize_lang("sr_RS@latin")   # 'sr'
normalize_lang("C")             # ''
```

Reduces a locale string to a lowercase two-letter code. Handles a `LANGUAGE`
priority list (takes the first entry), an encoding suffix, a `@modifier`, and
either separator style.

Returns `""` — not a default — when there is no language to find, so callers can
distinguish "unspecified" from an intentional fallback.

### `detect_language(env=None)`

Returns the preferred language from the environment, or `"en"`.

| Order | Source |
| --- | --- |
| 1 | `LANGUAGE` (first entry of the priority list) |
| 2 | `LC_ALL` |
| 3 | `LC_MESSAGES` |
| 4 | `LANG` |
| 5 | the C library locale |
| 6 | `"en"` |

`C` and `POSIX` values are skipped rather than treated as English. Pass `env` —
a mapping — to make it testable without touching `os.environ`.

### `is_rtl(language)`

```python
is_rtl("ar")   # True
is_rtl("en")   # False
```

Whether the language is written right-to-left, from a static table.

### Constants

| Name | Value |
| --- | --- |
| `DEFAULT_LANGUAGE` | `"en"` |
| `RTL_LANGUAGES` | The right-to-left language codes |
| `FRAMEWORK_LOCALES_DIR` | Where Gesso's own catalogs live in the package |

## Not implemented

Plural rules and locale-aware number/date formatting need real CLDR data and are
planned as an optional backend, not built in. See
[Internationalisation](../concepts/internationalisation.md#what-is-not-here).
