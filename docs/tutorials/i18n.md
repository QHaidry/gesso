# Translate an application

**You will end up with** two catalogs, correct plural forms, a language that
follows the system when it should, and a user override that wins.

No Qt. About fifteen minutes.

## 1. Write a catalog

A catalog is JSON, looked up by dotted key. `examples/tutorials/locales/en.json`:

```json
{
  "greeting": {
    "title": "Pomodoro",
    "hello": "Hello, {name}!",
    "labelled": "Press {key} to continue.",
    "items": {
      "one": "{count} item",
      "other": "{count} items"
    }
  }
}
```

There is nothing to compile and no `.po`/`.mo` step: the catalogs ship as-is
and are read at runtime.

## 2. Point a translator at them

```python
from gesso.i18n import DEFAULT_LANGUAGE, DirectorySource, Translator, detect_language

translator = Translator(
    [DirectorySource(LOCALES, name="application")],
    language=detect_language() or DEFAULT_LANGUAGE,
    fallback=DEFAULT_LANGUAGE,
    include_framework=False,
)
```

`detect_language()` reads `LANGUAGE`, `LC_ALL`, `LC_MESSAGES` and `LANG`, in
that order, and returns `""` for the values that mean "unset" — `C`, `POSIX`,
and an unset variable. That is why it is `or DEFAULT_LANGUAGE` and not a
default argument: **an empty detection is a real answer**, not a missing one.

```console
$ python examples/tutorials/greeting.py
detected from the environment: en
active language:  en
```

```console
$ LANGUAGE=fr_FR.UTF-8 python examples/tutorials/greeting.py
detected from the environment: fr
active language:  fr
```

## 3. Look things up

```python
translator.t("greeting.hello", name="Ada")     # 'Hello, Ada!'
```

`{name}` is filled from the keyword arguments. A missing key comes back as
**itself**:

```python
translator.t("greeting.untitled")              # 'greeting.untitled'
```

Not an empty string — an empty string looks like a layout bug, while a raw key
is visible on screen *and* greppable in your source.

!!! note "The key argument is positional-only"

    ```python
    def t(key_name: str, /, *, default=None, **kwargs) -> str
    ```

    That `/` is load-bearing. A translation is allowed to contain a placeholder
    called `key`:

    ```json
    "labelled": "Press {key} to continue."
    ```

    ```python
    translator.t("greeting.labelled", key="Ctrl+K")   # 'Press Ctrl+K to continue.'
    ```

    Without the positional-only marker, `key="Ctrl+K"` would collide with the
    parameter of the same name and raise `got multiple values for argument
    'key'`. Gesso found this because a real application wanted to say "press
    {key}".

## 4. Get plurals right, by hand

Gesso does **not** guess plural rules. The tutorial makes the consequence
explicit:

```python
def count_of(translator, key, count):
    form = "one" if count == 1 else "other"
    return translator.t(f"{key}.{form}", count=count)
```

```console
  0 -> 0 items
  1 -> 1 item
  2 -> 2 items
```

This is not laziness, and it is worth understanding before you reach for
`one`/`other` in a language you do not speak:

| Language | Plural forms |
| -------- | ------------ |
| English, French | 2 |
| Russian, Polish | 3 |
| Arabic | 6 |

Getting those right needs real CLDR data, which Gesso's
[roadmap](../roadmap.md) lists as a planned **optional** backend rather than
something the core pretends to have. Until then the catalogs carry the forms
and your application chooses — which has the side benefit that the rule is
visible in your code instead of hidden in a library's tables.

If you only ship English, this is the whole rule and you are done.

## 5. Let the user override you

Add their directory as a **later** source:

```python
sources = [DirectorySource(LOCALES, name="application")]
sources.append(DirectorySource(USER_LOCALES, name="user"))
```

Sources are consulted in **ascending priority** — later wins:

```console
$ python examples/tutorials/greeting.py --language fr
application only: Pomodoro
with the user's:  Pomodoro (personnalisé)
```

The `fr.json` that produced that second line is four lines:

```json
{ "greeting": { "title": "Pomodoro (personnalisé)" } }
```

In a real application that directory lives beside the user's *settings*
(`~/.config/<app>/i18n/`), not beside your code. It is next to the tutorial
only so the example stands alone. `Translator.for_app(context, ...)` wires that
up for you:

```python
translator = Translator.for_app(context, language=..., locale_dir=LOCALES)
```

## 6. And know which way is right-to-left

```python
is_rtl(translator.language)     # False for 'fr', True for 'ar' or 'he'
```

Gesso ships the language list and the question; it does **not** flip your
window for you. `run_app` applies the direction to the whole application,
because Qt mirrors every widget without any of them knowing — which is the
only way it is ever going to be done correctly. See
[the shell tutorial](shell.md).

## The test that actually saves you

A missing translation does not fail. It prints English. Nothing raises, your
tests stay green, and the bug ships.

The only cheap defence is comparing the catalogs key-for-key:

```python
def keys_of(catalog, prefix=""):
    found = set()
    for key, value in catalog.items():
        path = f"{prefix}.{key}" if prefix else key
        found |= keys_of(value, path) if isinstance(value, dict) else {path}
    return found


def test_the_catalogs_cover_the_same_keys():
    assert keys_of(load_catalog("en")) == keys_of(load_catalog("fr"))
```

Two more from the examples are worth stealing:

```python
# Every key resolves, rather than coming back as itself.
unresolved = [k for k in sorted(keys_of(catalog)) if translator.t(k) == k]
assert unresolved == []
```

That one catches a **dotted key name written inside JSON**. `"theme.help": "…"`
is a literal key, not a nested one, so the lookup walks into the string
`"Palette"` and gives up — silently. [Tracker](../examples/tracker.md) shipped
five of those until a test like this found them.
